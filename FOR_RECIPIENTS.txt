画像・動画かくしツールの起動方法

Mac の方:
1. zip を展開します。
2. start_mac.command をダブルクリックします。
3. 初回だけ必要なライブラリを自動で準備します。
4. 準備が終わるとアプリが起動します。

▼「"start_mac.command" は開発元を確認できないため開けません」と表示された場合:

  方法1（かんたん）:
    start_mac.command を右クリック →「開く」→ 確認ダイアログの「開く」をクリックします。

  方法2（ターミナルを使う）:
    ① Launchpad などからターミナル（Terminal）を起動します。
    ② ターミナルに次のように入力します（最後にスペースを入れてください）:
         bash 
    ③ Finder で start_mac.command をターミナルウィンドウにドラッグ＆ドロップします。
    ④ Enter を押します。

Windows の方:
1. zip を展開します。
2. start_windows.bat をダブルクリックします。
3. 初回だけ必要なライブラリを自動で準備します。
4. 準備が終わるとアプリが起動します。

注意:
- 初回起動時はインターネット接続が必要です。
- 初回起動は数分かかることがあります。
- Mac で Python の準備が必要と表示された場合は、Python 3.12.10 のインストーラが開きます。インストールしてから、もう一度 start_mac.command を開いてください。
- Windows で Python 3 が入っていない場合は、Python 3.12.10 を自動でインストールします。終わったら、もう一度 start_windows.bat を開いてください。
- 2回目以降は初回より速く起動します。
