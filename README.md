# 画像・動画かくしツール

画像や動画に写っている顔、または手動で選んだ範囲を隠すためのGUIツールです。

## できること

- 画像と動画の両方に対応
- 顔を自動検出して隠す
- 動画では一瞬の顔検出漏れを前後フレームの位置保持で補う
- 顔認識のレベルを調節できる
- 手動で選んだ範囲を、好きな色や斜線・チェック柄で塗りつぶす
- 動画では、途中のフレームから手動範囲の塗りつぶしを開始できる
- 動画では、CSRT/KCF/MOSSE と Kalman フィルターを組み合わせて手動範囲を追従させられる
- 動画では、追従対象を見失ったあと一定フレームを過ぎると手動マスクを消す。対象の見た目が大きく変わった場合も見失いとして扱います。
- プレビュー画面でズームしながら範囲を指定できる
- 書き出し前に仕上がりをプレビューできる
- 3ステップ構成のGUIで、設定と書き出しを同じ画面から操作できる
- 画面に収まらない場合は縦スクロールできる
- 隠し方をモザイク、ぼかし、黒塗りから選べる

## 対応形式

画像:

- `.jpg`
- `.jpeg`
- `.png`
- `.bmp`
- `.webp`
- `.tif`
- `.tiff`

動画:

- `.mp4`
- `.mov`
- `.m4v`
- `.avi`

## 受け取った人向けの起動方法

zipを展開したあと、OSに合わせて次のファイルをダブルクリックします。

Mac:

```text
start_mac.command
```

Windows:

```text
start_windows.bat
```

初回起動時に `.venv` を作成し、必要なライブラリを自動でインストールします。初回だけインターネット接続が必要で、数分かかることがあります。

Mac では、GUI部品の Tkinter が使える Python 3 を自動で探します。見つからない場合は Python 3.12.10 の公式インストーラをダウンロードして開き、案内を表示して停止します。

Windows で Python 3 が入っていない場合は、Python 3.12.10 の公式インストーラをダウンロードして実行します。インストール後、もう一度起動スクリプトを開いてください。

補足: Python 3.12.13 は公式にはソース配布のみで、macOS/Windows のインストーラーが提供されていません。そのため、この配布スクリプトでは 3.12系で公式インストーラーがある Python 3.12.10 を使います。

## 開発中の起動方法

仮想環境を使って起動します。

```bash
.venv/bin/python mask_video_gui.py
```

## 使い方

1. `画像・動画をえらぶ` から処理したいファイルを選びます。
2. 必要に応じて `顔をかくす` をオンまたはオフにします。
3. 顔検出の強さを変えたい場合は、`顔認識のレベル` を調節します。低くすると検出されやすく、高くすると確実な顔だけを検出します。
4. 手動で隠したい場所がある場合は、手動範囲の色・デザインを選んでから `塗る範囲をえらぶ` を開きます。
5. プレビュー上でドラッグして四角を描きます。
6. 動画の場合、シークバーで目的のフレームへ移動してから四角を描くと、そのフレーム以降だけ塗りつぶされます。
7. 必要なら `塗る範囲を動くもの（人・物）に追従させる` をオンにします。
8. `仕上がりプレビュー` で、書き出し前にマスク後の見た目を確認できます。
9. `スタート` を押すと、元ファイルと同じフォルダに `元ファイル名_かくし済み` の名前で保存されます。

## プレビュー操作

手動範囲の色・デザイン:

- 色: 黒、白、赤、青、緑、黄
- デザイン: ベタ塗り、斜線、チェック
- 顔の隠し方とは別設定です。顔は `顔のかくし方`、手動範囲は `手動範囲の色・デザイン` で調整します。

範囲選択プレビュー:

- マウス左ボタンを押したままドラッグ: 塗る範囲を追加
- 拡大中に端までドラッグ: 表示位置を自動でスクロール
- 右クリック: クリックした範囲を削除
- `ひとつ戻す`: 最後に追加した範囲を削除
- `すべて消す`: 選んだ範囲をすべて削除
- `+` / `-`: プレビューを拡大・縮小
- `全体表示`: 表示倍率を戻す
- マウスホイール: プレビューを拡大・縮小
- トラックパッドのピンチ操作: 対応している環境ではプレビューを拡大・縮小

仕上がりプレビュー:

- 画像: 現在の設定でマスクした結果を表示
- 動画: 現在の設定でマスクした結果を先頭から軽量再生
- `最初から`: 動画プレビューを最初から再生し直す

## 出力

画像は元の拡張子のまま保存されます。

例:

```text
photo.jpg -> photo_かくし済み.jpg
```

動画は `.mp4` として保存されます。

例:

```text
movie.mov -> movie_かくし済み.mp4
```

## 必要なもの

- Python
- OpenCV
- Pillow
- ffmpeg

このプロジェクトでは `.venv` 内のPython環境を使う想定です。

通常の配布では、`start_mac.command` または `start_windows.bat` が `.venv` の作成とライブラリのインストールを自動で行います。

## 配布用zipの作り方

配布用zipは次のコマンドで作成できます。

```bash
.venv/bin/python make_zip.py
```

作成されるファイル:

```text
video_masker_app.zip
```

zip作成時は、作業フォルダ内の動画・画像ファイルや `.venv` は含めません。

## 顔検出モデル

顔検出には YuNet のモデルファイルを使います。

```text
face_detection_yunet_2023mar.onnx
```

モデルファイルがない場合は、顔検出を使う初回処理時に自動でダウンロードします。

## 開発メモ

主な構成:

- `mask_video_gui.py`: GUI起動用の入口
- `video_masker/gui/app.py`: メイン画面
- `video_masker/gui/roi_selector.py`: プレビューと範囲選択
- `video_masker/gui/preview.py`: 書き出し前の仕上がりプレビュー
- `video_masker/processing.py`: 画像・動画のマスク処理
- `video_masker/masking.py`: モザイク、ぼかし、黒塗り
- `video_masker/media.py`: 画像・動画の判定と画像読み書き
- `video_masker/model.py`: 顔検出モデルの管理
- `video_masker/tracking.py`: 動画追従用トラッカー
- `video_masker/system.py`: 保存先フォルダを開く処理
- `requirements.txt`: 起動スクリプトがインストールするライブラリ
- `start_mac.command`: Mac向けの自動セットアップ・起動スクリプト
- `start_windows.bat`: Windows向けの自動セットアップ・起動スクリプト
- `make_zip.py`: 配布用zipを作成するスクリプト

機能や操作方法を変更した場合は、このREADMEも必要に応じて更新してください。
